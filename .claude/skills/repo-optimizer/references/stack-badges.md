# Stack badges

shields.io badge markdown per technology. Every `logo=` slug below was verified to
render an actual logo — do not invent new slugs. If a technology is missing, check
first at <https://simpleicons.org>; if there is no icon, use the fallback pattern
at the bottom rather than a broken one.

## Badge row (header)

Put 4–8 badges under the title, most defining technology first
(framework → language → frontend → infrastructure). Use `style=for-the-badge`.

```markdown
<p align="center">
  <img src="https://img.shields.io/badge/Laravel-FF2D20?style=for-the-badge&logo=laravel&logoColor=white" alt="Laravel">
  <img src="https://img.shields.io/badge/Filament-FDAE4B?style=for-the-badge&logo=filament&logoColor=black" alt="Filament">
  <img src="https://img.shields.io/badge/PHP-777BB4?style=for-the-badge&logo=php&logoColor=white" alt="PHP">
  <img src="https://img.shields.io/badge/Docker-2496ED?style=for-the-badge&logo=docker&logoColor=white" alt="Docker">
</p>
```

## No icon available

`pest` and `phpunit` have no simple-icons entry. Use the PHP logo with the tool's
own color rather than a slug that silently renders nothing:

```markdown
https://img.shields.io/badge/Pest-6C5CE7?style=for-the-badge&logo=php&logoColor=white
https://img.shields.io/badge/PHPUnit-366488?style=for-the-badge&logo=php&logoColor=white
```

For anything else with no icon, drop `logo=` entirely — a clean text badge beats a
broken image:

```markdown
https://img.shields.io/badge/Tool_Name-4A5568?style=for-the-badge
```

## Verifying a new slug

shields.io returns HTTP 200 even for unknown logos, so the status code proves
nothing. Check that a logo was actually embedded:

```bash
curl -s "https://img.shields.io/badge/x-000?logo=SLUG" | grep -q 'data:image' \
  && echo "logo exists" || echo "no logo - drop the logo parameter"
```
